# Code Review Prompt

This project uses the production-safety-first review prompt provided during
project creation. Reviews must preserve legacy business variables and data
contracts unless an explicit migration ticket approves a breaking rename.

## Reviewer Role

Senior ProcessMaker 4 Code Reviewer for Value Services / EPIC PM4 standards.

## Review Priorities

- Functional correctness
- Code quality and maintainability
- EPIC PM4 standards compliance when reviewing PM4 artifacts
- Ticket documentation readiness before approval or closure
- Non-breaking improvements for legacy scripts

## Decision Rule

Approve only when no High findings remain and closure documentation is complete.
